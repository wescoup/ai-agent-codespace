# Agent-Lab-Personal 🧪

This is my private playground for testing AI agents, MCP servers, and CAD automation.

## Setup
1. Copy `.env.example` to `.env`.
2. Add your API keys to `.env`.
3. The `devcontainer` has already installed all Python requirements.
